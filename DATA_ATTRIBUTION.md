# Data attribution

The element-property dataset in `elements-data.js` is adapted from [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) by Bowserinator, which is distributed under the [Creative Commons Attribution-ShareAlike 3.0 Unported license](https://creativecommons.org/licenses/by-sa/3.0/).

The adaptation keeps selected numeric and classification fields and localizes the interface. Element sample-photo URLs and their supplied credits are shown in each detail card; the photos are hosted by Wikimedia Commons and may have different licenses, as noted in each credit. The adapted element dataset is offered under CC BY-SA 3.0. The interface and application notes are separate project content.
